06 / 出力

ココフォリア出力時の重ね順です。数字が大きいほど上に来ます。初期状態ではカード本体が一番上です。
確認レイアウトは PC / 台本 / カード / 地図 / 非公開 / 操作 の各ゾーンへ規則的に並べます。カード数が多い場合は縦方向へ自動拡張し、同一座標に重ねません。シーン入りZIPには 00_作者確認、00_全TL、00_事件真相、00_メモ対応表も追加されます。
実験機能：1つのルームZIPにシーン一覧を作成します。盤面背景と黒いシーン矢印は常設スクリーンパネル、 現在シーンの白矢印・シーン案内・専用マーカーはシーン側マーカーパネルとして切り替えます。各シーンの外部BGM設定はシーン切替メッセージの /bgm コマンドとして保存されます。
