# このサイトの使い方

:::note このサイトについて
『お母さんは大統領』の制作INDEX（改訂版）。2026-10-05に行った総点検・改稿の結果をそのまま載せている。前の版（AUTHOR INDEX v2.1）は「参照・旧版」から開ける。
:::

## 画面の見かた

| 場所 | 役割 |
|---|---|
| 左のサイドバー（左列） | 大題。HO・読み合わせ・カードなどの大きな分類 |
| 左のサイドバー（右列） | 中題。選んだ大題の中のページ一覧。開いているページの見出しも、その下に並ぶ |
| 中央 | 本文 |
| 右のサイドバー | 修正案。必要なときだけ開く。たたむと細い帯になる |

- サイドバーの幅は、境目の線をドラッグして変えられる（左右とも。左は大題と中題の境目も動かせる）
- 幅はこの端末に記憶される。たたむ・開くは上部のボタンか、サイドバーの「＜」「＞」で行う

## 修正案の残し方

1. 本文の直したい段落・台詞・表の行にカーソルを合わせると、右端に「✎」が出る（スマホでは、その行を一度タップする）
2. 「✎」を押すと右のサイドバーが開き、その箇所の修正案を書ける
3. 書いた内容は自動で保存される。「反映済み」にすると、一覧で区別できる
4. 修正案のある箇所には、本文の右端に印が付く（黄色＝未反映、緑＝反映済み）
5. 右のサイドバーの「このページ」「すべて」で一覧を見られる。「すべて」から、未反映の修正案をMarkdownで書き出して、Claudeに渡せる

## 共有保存（編集キー）

- 閲覧と修正案の表示には、キーは要らない
- 上部の「編集キー」から作者用の編集キーを入れると、修正案が共有保存（Cloudflare D1）に保存され、ほかの端末でも見られる。解除は30日間有効
- キーを入れていない間も、修正案は「この端末の下書き」として残る。あとで解除すると「下書きを共有へ送る」で送れる
- 同じ箇所を別の端末で同時に直した場合は、上書きせずに知らせる

:::note 公開について
このサイトとメモは、URLを知っている人なら誰でも読める（GitHub Pagesの公開サイト）。真相やGM情報も載っているので、プレイヤーにURLを教えないこと。修正案に個人情報やパスワードを書かないこと。
:::
