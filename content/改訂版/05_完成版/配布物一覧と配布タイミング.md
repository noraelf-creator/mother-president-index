# 配布物一覧と配布タイミング（GM用）

`プレイヤー配布/` の中身を、いつ・誰に渡すかの一覧。**読み合わせは事前に配らず、その場面で表示する**（結果の分岐や真相を含むため）。

| 時期 | 対象 | ファイル |
|---|---|---|
| 開始前 | 全員 | `00_共通HO.md` |
| 開始時 | 各PC本人 | `HO/PCx_名前/①初期HO`（ルークは「本当の性癖」をGMにだけ伝える） |
| オープニング | 表示 | `読み合わせ/R01`、`R02` |
| 第0事件の開始 | 表示 | `読み合わせ/R03` |
| R03の後 | 各PC本人 | `HO/PCx_名前/②第0事件HO` |
| R03の後 | サラーだけ | `HO/PC1_サラー/別紙_サラー専用_小道具の秘密選択（カード7）`（周りに気づかれないように） |
| 前半・後半 | 表示 | `カード/調査カード_第0事件_前半（1〜4）`、`後半（5〜8）`。カード7は、サラーが選んだA/B/Cの本文を公開時に表示（原本はGM資料のカード原本） |
| 前半の後 | 表示 | `読み合わせ/R04` |
| R04の後 | マーティだけ | `HO/PC4_マーティ/別紙_マーティ専用_教授への聞き込み結果` |
| 後半の後 | 全員 | `カード/第0事件_推理メモと投票` |
| 投票の後 | 表示 | `読み合わせ/R05`（最多得票者の分岐だけ）→ `R06` → `R07` → `R08` → `R09` |
| R09の後 | 各PC本人 | `HO/PCx_名前/③カーチェイスHO` |
| 各ROUND | 表示 | `読み合わせ/R10`（成功か失敗の一方）、ROUND4の後 `R11` |
| 休憩の後 | 各PC本人 | `HO/PCx_名前/④別荘HO` |
| 別荘の夜 | 表示 | `読み合わせ/R12` → `R13`（代読の告知を先に）→ `R14` |

| 全12枚公開後 | 各PC本人 | `追加観察/追加観察_○○票`（第0事件でその人が投票した相手のもの） |
| 最終推理 | 全員 | `カード/最終推理シート` |
| 全員の回答公開後 | 表示 | `読み合わせ/R15` → `R16`〜`R22` → `R23` |
| ラスト | 表示 | `読み合わせ/R24` → `R25` → `R26`（解放状況と希望に応じて） |
