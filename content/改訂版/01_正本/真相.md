## 0. ひとことで

**誰もサラーを本気で殺そうとしていなかった。**
ドクの薬品取り違え、ルークの寝ぼけたハンマー、マーティの死亡偽装。三つの事故と悪ふざけが一晩のうちに重なり、サラーの身体は「何度も殺されたように」見えた。ジョンは逃げ出しただけで、サラーには触れていない。

## 2. 第0事件「未来人は誰だ！？」の真相

1. 16:40、**サラー**がバス停で未来人ごっこをした。西暦と現在の大統領を尋ね、「間に合った……」「絶対、今度は救ってみせる」と言って去った（元祖）。
2. **ルーク**の少年時代の黒歴史ノート（青い表紙）が、今日の研究室の机に置かれた。ルークは17:25〜17:45に印刷室へ行き、ノートから目を離した（原典）。
3. その間に**ドク**が計算機を取りに研究室へ戻り、ノートを読んだ。付箋を「世界か、一人の大切な彼女か」のページへ動かした。
4. ドクはサラーの演技を面白がり、ノートの台詞を引用して**18:10に東門で第二の未来人を演じた**（模倣犯）。口癖は使っていない。
5. サラーは第二の人物ではない。ノートも読んでいない。ただし公開証拠からは、その可能性が完全には消えない。サラーは18:20〜18:28に未来人らしい小道具を自分で作り、鞄に入れた（カード7）。
6. ルークは台詞の作者だが、今回は演じていない。
7. **マーティは本物の未来人（アンドロイド）**。第二の人物ではない。調査中に教授へ聞き込みをした結果、「また未来人っぽい女がいた」という新しい噂を生んだ（本物）。
8. カード8の紙片は4人とも置いていない。誰が残したかは確定しない。

**推理の着地点**：「第二の未来人として一番自然なのはドク」。ドクだけに確定する決定打はない。サラーは自分から対抗馬として疑いを集められる。

**投票**：「未来人の犯人は誰？」は意味を定義しない公開投票。正解・不正解は判定しない。最多得票者に応じた短い分岐を1つ読み、共通開示でドクが実行を認める。マーティの正体と紙片の出所は保留したまま本編へ進む。

## 3. 別荘事件の真相

### 3-1. サラーの最終的な状態
口元の泡と唇の変色（毒）／後頭部の強い打撃／刃物傷／銃創／雨・泥・黒い煤。それでも本人は無事。

### 3-2. 原因の分解（それぞれ独立している）

| 傷・汚れ | 原因 | 意図 |
|---|---|---|
| 毒の症状 | **ドク**。21:30、サラーとマーティに渡した飲み物へ「罰ゲーム用・激苦」を入れるつもりで、よく似た小瓶の**研究用薬品**を入れた | 悪戯（激苦）。取り違えに気づいていない |
| 泥酔（記憶の曖昧化、配管への叫び、収納箱・斧の騒ぎ） | ドクがサラーの飲み物にだけ入れた**強い酒**（食糧庫の酒） | 悪乗り。**毒の副作用ではない** |
| 後頭部の打撃 | **ルーク**。23:00、悪夢の中で手元の護身用ハンマーを振り回し、開いた窓の外へ投げた。真下の別荘南側にいたサラーの後頭部に命中 | 事故。命中したことを知らない |
| 刃物傷・銃創・雨・泥・煤 | **マーティ**。23:30、南側で倒れていたサラー（頭部負傷済み・生存）を発見。24:00、非常梯子で屋上へ運び、日本刀で斬り、拳銃を一発撃ち、煙突からリビングの暖炉へ落とした | **死亡偽装**。サラーはこの程度では死なないと知っており、未来の追跡者に「サラーは死んだ」と思わせるため |
| ― | **ジョン**。ポスター裏の壁穴から脱出しただけ | サラーへの直接加害なし |

### 3-3. ジョンの脱出経路
2階ジョンの客室 → マリリン・モンローのポスター → 壁穴 → 古い設備空間（壁の中） → 大型排水設備 → 崖下の排水口 → 敷地外。
**煙突は使っていない。** 崖下側から別荘南側へ直接登って戻る道はない。ジョンの経路とサラーの搬送経路は交差しない。

### 3-4. 22時台の「心霊現象」の正体（この順で起きた）

| リビングで聞こえたこと | 正体 |
|---|---|
| 「未来最高ーーー！！」 | 食糧庫で古い配管に向かって叫んだ、酔ったサラー |
| 壁の中の大きな金属音 | 壁内の設備空間を移動するジョン |
| 「お母さんは大統領になるなよーーー！！」 | 未来を変える決意を叫んだジョン |
| 「お母さんは大統領……」 | 酔ったサラー（ジョンの声への返事のつもり） |
| 照明の明滅・停電 | 自室で毒を分解していたマーティの大量電力使用 |
| 「I'll be back.」 | 停電後、配管に向かって叫んだ酔ったサラー |

### 3-5. サラーとドクのホラーコメディ（22:30）
ドクが怪異を煽る → 怖くなり、トイレへ逃げたように見せて**リビングの収納箱**に隠れる → かくれんぼのつもりのサラーが即発見 → 収納箱を揺らす → 箱が手からすっぽ抜けて廊下まで滑り、壁に激突 → ドクが自室へ逃げて施錠 → サラーが薪割り斧で扉を破壊 → 扉の穴から「ドクー？ あーそーぼー！」 → ドク気絶。停電中だったため、ドクは相手の顔を見ていない。誰も怪我をしていない（血痕なし）。

### 3-6. 事件発覚（24:30）
24:00、ドクの部屋にいたルークとドクが煙突からの落下音を聞く。怖がりながらリビングへ降り、24:30に暖炉のそばのサラーを発見する。マーティは屋外から回って玄関から普通に入ってくる（雨でずぶ濡れ）。サラーはルークに抱き起こされて目を覚ます。
【追加】サラーは目覚めた直後、ルークに抱えられているのが嬉しくて少しだけ寝たふりをする（旧稿の心情を、v3の時系列を壊さない範囲で採用）。

## 7. 意図的な違和感・ミスリード（消さないこと）

- 第0事件：マーティの調査行動そのものが未来人らしく見える（本物なのに、推理上は「印象が怪しい」枠）。カード8の紙片は解け残る。サラーは自分から疑いを集めに来る。
- 別荘：22時台の声は心霊現象に見える。ジョンの手記は「母を止める」動機を示し、ターミネーター的に「ジョンがサラーを狙った」と思わせる。リビングで発見されたのに血が少ない。「I'll be back.」はマーティ（テルミネーター）を連想させるが、実はサラー。収納箱と斧の跡は襲撃に見えるが、血痕がない。
- 伏線：古びたノート（未来から持ち込まれたルークのノート）、［重版］の本（未来のドクの著書）、「お母さんは大統領になるなよ」（ジョンの正体）、拾得物の「88」。
