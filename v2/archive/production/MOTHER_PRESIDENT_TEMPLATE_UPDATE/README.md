# お母さんは大統領・正式素材差し替え版

index.html をブラウザーで開いてください。インターネット接続は不要です。元の成果物は変更していません。

## 変更点

- 4x.zip の正式素材から、立ち絵4人、顔トークン4人、1F／2F地図、タイトル、中央飾り線を差し替え。
- PC1～4の色別本マークに、HO／カーチェイス／追加HOの正式ラベルを合成。EX上下12枠は正式黒本マーク＋編集可能な名称を使用。
- PC番号・初期キャラクター名も正式素材を使用。キャラクター名を編集した場合は文字表示に切り替わります。
- 立ち絵は透明余白を除去し、比率を維持して枠内下揃え。旧版の乗算による着色を解除。
- 捜査10枠・議論12枠のまま、カードを97×73に調整。議論の段位置は448／527／613。カード削除で他カードは移動しません。
- 1600×900、主要領域、テンプレートID、保存形式、他11テンプレートは維持。

## ファイル

- index.html / mother-president.js / mother-assets.js：本体（画像も同梱埋め込み）
- assets/4x/：提供された画像原本。使用対応は asset-mapping.json を参照。
- 01_空テンプレート.png / 02_サンプルカード配置版.png：1600×900プレビュー
- empty.project.json / sample.project.json：読込用データ
- sample_ccfolia.zip：サンプルのココフォリア用出力
- verification.json：自動動作確認結果

## 残る差異・未解決事項

- 参考画像由来の切り出し画像は、初期盤面では使っていません。すべて提供ZIPの画像または既存の図形・文字描画です。
- カード枠、フェーズ枠・文字、BACK／NEXT、PCの背景・外枠は従来の描画を維持。仮の写真・立ち絵はありません。
- 参考画像の議論欄は16枠ですが、既存仕様の12枠を優先して3段×4枠を維持。そのため左側の余白は参考画像と異なります。
- 顔や名前の位置は公式画像の比率を維持したため、参考画像と完全一致ではありません。
- サンプルカードは動作確認用の仮内容です。実シナリオのカード本文・EX内容を登録してください。
- ココフォリア実サービスへのインポートは未実施です。次の確認は sample_ccfolia.zip をテストルームへ読み込むことです。
- 以前保存したJSONを読み込むと、そのJSON内の旧画像も復元されます。既存ユーザーデータは自動上書きしません。正式素材で開始する場合は同梱の empty.project.json を読み込んでください。
