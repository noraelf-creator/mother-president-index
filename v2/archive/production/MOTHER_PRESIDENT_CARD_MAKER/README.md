# CARD MAKER / カード工房 第2弾

index.htmlを開き、プレビュー上部の「カード工房」を押してください。第1弾の全体編集を含みます。前回成果物は変更していません。

## 使い方

1. 「追加」でカードを作成、または「サンプル12枚を追加」。同梱sample.project.jsonを既存の読込ボタンで開いても開始できます。
2. ID、種別、対応PC、EXマーク、固定配置先を選択。
3. 表面／裏面を切り替えてタイトル、本文、補足、色、画像を設定。
4. 文字サイズ、行間、余白、画像高さを調整。入力後に別の欄をクリックするとプレビューへ反映されます。
5. 単体拡大と盤面の縮小表示を見比べます。盤面倍率100%は横スクロールできます。
6. 表示面PNG、一括PNG ZIP、manifest、CARD_PACK.zipを出力。
7. 編集を続けるための保存は「プロジェクトJSON保存」。CARD_PACKは画像素材の配布用です。

## 仕様

- カードは600×840。ココフォリア専用の必須サイズではなく、読み物向けの縦長比率として採用。
- 表裏は独立したタイトル・本文・補足・画像・色・文字設定。文字は自動縮小しません。
- 収まらない文章はプレビューでクリップされ、明確な警告が出ます。警告がある面の単体PNG、または警告があるカードを含む一括出力は止まります。
- カードIDは英数字・ハイフン・下線。重複ID、表裏ファイル名衝突、重複配置先を検出。
- 配置先はinvestigation_01〜10、discussion_01〜12、ex_01〜12。未配置でも単体作成・出力できます。
- 盤面上の仮配置はmother_president専用。第1弾の調整済み座標も参照します。既存の盤面カード本文・配置を上書きしません。
- 縦長画像を横長固定枠に比率維持で表示するため、小さく見えます。盤面上で長文を読めることを保証するものではありません。
- カード種別と配置先は独立。サンプル調査12枚は捜査10枠＋議論2枠に配置しています。議論12枚の比較PNGも同梱。

## 出力

CARD_PACK.zipにはcards/内の表裏24PNG、card_manifest.json、README.txtが入っています。
表面はcardId.png、裏面はcardId_back.png。manifestにcardId/type/targetSlot/front/back/pc/exMarkとテキストを保存。
「カード一括PNG」はブラウザーの複数ダウンロード制限を避けるためZIP形式です。

## 範囲外

BASE_BOARD.zipとの自動合成、ルームZIP化、マーカー工房は未実装。CARD_PACK.zipはココフォリアへそのまま部屋としてインポートするZIPではありません。
ココフォリア実サービス上での表示確認は未実施。ブラウザー上のカード・盤面プレビューとPNG・ZIPを検証済みです。
第1弾同様、既存ココフォリアZIP出力への全体編集座標反映は未対応です。
