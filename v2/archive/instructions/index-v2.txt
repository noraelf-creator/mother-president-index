【マダミス-4『お母さんは大統領』】
作者用HTML INDEXサイト 改修版指示書
全資料収録／常時全文表示／ページ内直接メモ方式

現在制作中のマーダーミステリー

『お母さんは大統領』

について、

最初から最後までの全資料を一か所から確認できる
作者用HTML INDEXサイトを作成してください。

マダミス6で使用した
「INDEX HTMLから全資料へ移動できる形式」
を発展させます。

今回は特に、

【資料を読む】
↓
【気になった場所のすぐ下にメモを書く】
↓
【後でそのメモを見ながら修正する】

という使い方を最優先してください。

==================================================
■ 最重要変更
==================================================

以前の指示にあった、

「ネタバレを表示」
「真相を折りたたむ」
「クリックしないと秘密が見えない」

などの仕組みは不要です。

このサイトは作者専用です。

ページを開いたら、
HO、秘密、真相、作者用情報、EDなどを含め、

【そのページにある情報は最初から全部表示】

してください。

折りたたみで隠さないこと。

資料確認の速度を最優先します。

==================================================
■ 1. サイトの目的
==================================================

このサイトは、

・閲覧用資料集
・現在の正本
・過去資料保管庫
・訂正メモ帳
・制作進捗確認
・ココフォリア制作確認

を兼ねます。

このサイトを開けば、

『お母さんは大統領』について
現在何が決まっていて、
昔どうなっていて、
どこを直したいのか

まで全部分かる状態を目指してください。

==================================================
■ 2. Web公開
==================================================

このPCを起動していなくても、
別PCからURLで閲覧可能にしてください。

Google Driveではなく、
Webサイトとして公開してください。

基本候補：

GitHub Pages

ただし、
後述するメモ保存機能だけは
GitHub Pages単体では実現できないため、

Cloudflare Worker / Supabase Edge Function
＋軽量DB

などを使用して構いません。

==================================================
■ 3. 編集は「普通のログイン」ではなく編集キー方式
==================================================

ユーザーに、
メールアドレス＋パスワードのような
通常のアカウントログインを要求しないでください。

閲覧：

誰でも通常表示可能
またはURLを知っている人が閲覧可能。

編集：

画面上部の

【編集モードを解除】

を押す。

初回だけ、

【作者用編集キー】

を入力。

正しければ、
そのブラウザでは以後メモ編集可能。

可能なら、
一定期間ブラウザに保持してください。

毎回ログインさせないこと。

==================================================
■ 3-1. セキュリティ
==================================================

編集キーそのものを
HTML / JavaScript内へ平文で埋め込まないでください。

Web上から誰でも読み取れる形にしないこと。

編集処理は、

Cloudflare Worker
Supabase Edge Function
その他サーバー側処理

で編集キーを検証してください。

閲覧だけなら編集キー不要。

==================================================

非常に面倒です。

各資料のすぐ下へ、

==================================================
■ 4-3. メモUI
==================================================

複雑にしないでください。

基本は、

作者メモ：
[テキストエリア]

［保存］

だけでよいです。

追加であると便利：

・保存日時
・最終更新日時
・「反映済み」チェック

程度。

以前案の、

未対応
対応中
保留
反映済み

のような複雑なワークフローは必須ではありません。

今回の目的は、

【ざっと読んで、その場で一言メモする】

ことです。

==================================================
■ 4-4. 保存方式
==================================================

メモは端末をまたいで共有してください。

PC-Aで書いたメモを、
PC-Bから開いても同じように見えること。

localStorageだけに保存しないでください。

クラウドDBへ保存してください。

ただし、
DB障害時やオフライン時には
localStorageへ一時保存してもよいです。

復帰後に同期できれば理想。

==================================================
■ 4-5. 自動保存
==================================================

可能なら、

・入力後数秒で自動保存
または
・フォーカスを外した時に保存

にしてください。

ただし、

［保存］

ボタンも残してください。

保存された時は、

「保存しました」

程度の小さな表示だけ。

ページ移動やモーダル表示は不要。

==================================================
■ 5. メモ一覧ページも補助的に残す
==================================================

各資料の下へ直接メモを書くのを主方式にします。

ただし、

【全メモ一覧】

ページも補助的に作ってください。

ここでは、

・資料名
・メモ内容
・更新日時
・反映済みか

を一覧表示。

重要：

メモ一覧を使わなくても、
各資料ページだけで普通に作業できること。

■ 11. サラーのスキル
==================================================

最新版では、

サラー固有スキル【横暴】

を必ず収録。

このスキルによって、

通常では確認できない追加情報を
強引に確認できる。

について、

↓

という構造。

過去版の、

「誰でもポスターを剥がす宣言をすればよい」

は旧稿側へ残し、
最新版には使わない。
